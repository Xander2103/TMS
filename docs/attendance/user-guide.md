# Urenregistratie — gebruikersgids

## Voor medewerkers

**Hoe punt ik in?** Op je dashboard (of Mijn portaal) staat de kaart **Werkstatus** met
één grote knop **Inpunten**. Aan de prikklok: tik je code in en kies **Inpunten**.

**Hoe neem ik pauze?** Zelfde kaart → **Pauze starten**; daarna **Pauze beëindigen**.
Meerdere pauzes per dag zijn geen probleem. Uitpunten tijdens je pauze mag — de pauze
stopt dan vanzelf.

**Hoe punt ik uit?** **Uitpunten** op de kaart of aan de prikklok. Vergeten? Je krijgt
een melding; vraag HR om een correctie met het juiste tijdstip.

**Hoe bekijk ik mijn uren?** Menu **Mijn uren** (of de link op de werkstatuskaart):
vandaag/deze week/deze maand, per dag je punches, pauzes, netto gewerkte tijd, je
geplande uren en het verschil. Correcties staan er leesbaar bij (wie, wanneer, waarom).

**Chauffeurs**: bovenaan de chauffeursapp staat de kaart **Werkdag** met dezelfde
knoppen plus je dagcijfers en planning. Zolang er geen tachograafkoppeling is, staat er
eerlijk "Tachograafdata niet gekoppeld".

## Voor HR

**Hoe zie ik wie momenteel aanwezig is?** Personeel → **Aanwezigheid**: live per
medewerker de status (Aan het werk / Pauze / Niet ingepunt / Uitgepunt / Afwezig /
Vergeten uit te punten?), sinds wanneer, gewerkte tijd en pauze, met tellers bovenaan en
filters op datum, afdeling, status en naam. Het overzicht ververst elke 30 seconden.
Klik op een rij voor de volledige registratie van die medewerker.

**Hoe corrigeer ik een vergeten uitpunt?** Medewerkerfiche → tab **Urenregistratie** →
bij de sessie **Corrigeren** → vul het werkelijke uitpuntmoment in → **reden is
verplicht** → opslaan. Het origineel blijft altijd zichtbaar in de historiek
("gecorrigeerd vanuit … door … reden: …"). Volledig foutieve registraties **annuleer**
je (ze blijven traceerbaar maar tellen nergens meer mee); ontbrekende dagen maak je aan
via **+ Manuele registratie**.

**Hoe reset ik een PIN?** Zelfde tab, blok **Prikklokcode**: *Nieuwe code genereren*
(de code verschijnt precies één keer — geef ze meteen door) of een eigen code instellen.
Codes zijn nooit opvraagbaar; *Intrekken* blokkeert de prikklok voor die medewerker.
Een geblokkeerde code (te veel foute pogingen) los je ook op met een nieuwe code.

**Rapporten**: Rapporten → HR → **Urenregistratie (XLSX)** of Personeel → Aanwezigheid
voor het live beeld. Het rapport toont per medewerker per dag bruto/pauze/netto,
gepland, afwijking, ontbrekende uitpunten en het aantal correcties.

## Voor de kioskbeheerder

**Hoe zet ik een prikklok op?** Instellingen → **Urenregistratie** → *Prikklok
toevoegen* → naam + locatie → kopieer de éénmalig getoonde provisioning-sleutel → open
op de tablet `/kiosk` → plak de sleutel → *Registreren* → zet de browser in kioskmodus
(volledig scherm). Details en beheer (sleutel vernieuwen, uitschakelen):
[kiosk.md](kiosk.md).

**Instellingen**: zelfde pagina — zelf punchen aan/uit, kiosk aan/uit, PIN-lengte,
drempel "vergeten uitpunten", marge "gepland maar niet ingepunt" en (bewust standaard
uit) automatisch afsluiten.
