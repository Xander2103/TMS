## WAT DOE JE HIER?

Je leest wat elke rol normaal doet en waarom je een scherm soms niet ziet.

## WANNEER GEBRUIK JE DIT?

Als je je afvraagt waarom een collega iets wel ziet en jij niet.

## STAPPEN

| Rol | Startscherm | Doet normaal |
|---|---|---|
| **Administrator** | Dossiers | Alles, ook gebruikers en rollen |
| **Management** | Dashboard | Bekijkt alles en keurt goed. Maakt geen opdrachten of ritten |
| **Planner** | Planbord | Opdrachten, dossiers, prijzen, planning |
| **Dispatcher** | Live opvolging | Lopende ritten, incidenten, afwijkingen. Ziet geen prijzen |
| **HR** | Medewerkers | Personeel, afwezigheden, bedrijfsmiddelen. Geen transport |
| **Wagenparkbeheerder** | Vlootoverzicht | Voertuigen, opleggers, onderhoud, schade |
| **Boekhouding** | Facturen | Facturen, tarieven, Peppol. Geen planning |
| **Magazijn** | Uitgiftes & retours | Uitgeven, retour, voorraad, laden en scannen |
| **Chauffeur** | Vandaag | Alleen de eigen ritten |
| **Klant** | Opdrachten in het klantportaal | Alleen de eigen opdrachten |

## WAT GEBEURT ER DAARNA?

Je startscherm en menu volgen je rechten. Wijzigt de beheerder je rol, dan gelden de nieuwe rechten bij je volgende actie. Je hoeft niet opnieuw aan te melden.

## WAAR MOET JE OP LETTEN?

- Dit zijn de standaardrollen. Een beheerder kan rollen per bedrijf aanpassen.
- Het verbergen van een knop is niet de echte beveiliging: ook de server controleert elke actie.

## VEEL VOORKOMENDE PROBLEMEN

**Je ziet een scherm niet dat je wel nodig hebt.** Vraag je beheerder om het recht. Zie [Geen toegang](help:geen-toegang).
