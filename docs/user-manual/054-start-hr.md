**Startscherm:** [Medewerkers](help:medewerker).

**Meest gebruikt:** Medewerkers, Afwezigheden, Aanwezigheid, Kwalificaties, Voorraad, Uitgiftes & retours.

**Normale dag:**

1. Volg afwezigheden en onvolledige dossiers op.
2. Maak nieuwe medewerkers aan.
3. Beheer bedrijfsmiddelen.
4. Verwerk vertrek via [offboarding](help:offboarding).

**Normaal niet:** transport (opdrachten, planning, dossiers, klanten, chauffeursprofielen), wagenpark, financiën, gebruikersaccounts aanmaken.
