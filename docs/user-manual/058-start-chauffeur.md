**Startscherm:** [Vandaag](help:chauffeur-start).

**Meest gebruikt:** Vandaag, Ritten, Incident, Documenten, Berichten.

**Normale dag:**

1. Open je rit op **Vandaag**.
2. Werk elke [stop](help:chauffeur-stops) af: aankomst, laden of lossen, afronden.
3. Neem bij elke levering het [afleverbewijs](help:chauffeur-pod) op.
4. [Meld problemen](help:chauffeur-probleem) meteen.

**Normaal niet:** een rit zelf starten, ritten van collega's zien, prijzen of documenten van de klant bekijken, planning wijzigen.
