## WAT DOE JE HIER?

Je volgt in welke fase een opdracht zit en je zet ze een stap verder.

## WANNEER GEBRUIK JE DIT?

Vooral om een conceptopdracht te bevestigen, zodat ze gepland kan worden.

## STAPPEN

![Een conceptopdracht met de knop Bevestigen](shot:opdracht-bevestigen "Een opdracht bevestigen")

1. Open de opdracht.
2. Controleer de gegevens.
3. Klik op **Bevestigen**.

| Status | Betekenis | Hoe kom je verder? |
|---|---|---|
| **Concept** | Nog in opmaak | **Bevestigen** |
| **Ingediend** | Aanvraag via het klantportaal | [Beoordelen](help:portaal-beoordelen) |
| **Bevestigd** | Klaar om te plannen | Op een rit zetten |
| **Gepland** | Op een geplande rit | Wanneer de rit start |
| **In uitvoering** | Onderweg | Als de rit klaar is |
| **Afgerond** | Uitgevoerd | Facturatie |
| **Gefactureerd** | Op een factuur | Eindstatus |
| **Geannuleerd** | Gaat niet door | Met een reden |

## WAT GEBEURT ER DAARNA?

Een bevestigde opdracht verschijnt op het [planbord](help:planbord) onder **Ongepland**.

## WAAR MOET JE OP LETTEN?

- Bevestigen kan pas met minstens één laadstop en één losstop.
- **Status corrigeren** (onder het menu van de opdracht) is voor fouten, met een verplichte reden. Het kan niet vanuit Gefactureerd en laat POD, scans en factuurgegevens ongemoeid.
- Via **Gebruik als sjabloon** maak je een nieuwe opdracht op basis van deze.

## VEEL VOORKOMENDE PROBLEMEN

- **"Een bevestigde opdracht heeft minstens één laad- en één losstop nodig."** Voeg de ontbrekende stop toe.
- **"Deze opdracht is intussen door iemand anders gewijzigd."** Laad de pagina opnieuw en probeer nog eens.
