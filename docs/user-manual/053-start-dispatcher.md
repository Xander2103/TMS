**Startscherm:** [Live opvolging](help:live-opvolging).

**Meest gebruikt:** Live opvolging, Ritlijst, Planbord, Incidenten, Afwijkingen.

**Normale dag:**

1. Start de ritten van vandaag met **Start rit**.
2. Hou de tellers in het oog.
3. Volg [mislukte leveringen](help:live-mislukt) op en maak [herleveringen](help:herlevering).
4. Behandel [incidenten en afwijkingen](help:incident-opvolgen).
5. Meld [vertragingen](help:live-vertraging).

**Normaal niet:** prijzen zien, opdrachten aanmaken of bewerken, dossiers beheren, klanten wijzigen, facturen.
