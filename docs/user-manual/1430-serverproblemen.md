## WAT DOE JE HIER?

Je leest wat je doet als het systeem even niet werkt.

## WANNEER GEBRUIK JE DIT?

Als je een van deze meldingen ziet.

## STAPPEN

![Het systeem in offline toestand met de melding bovenaan](shot:fout-offline "De melding bij geen verbinding")

| Melding | Betekenis | Wat doe je? |
|---|---|---|
| **Offline — scans, stopacties en incidentmeldingen komen in de wachtrij…** | Je hebt geen verbinding | Controleer je netwerk. Die acties worden later vanzelf verstuurd. |
| **De server reageert niet. Probeer het opnieuw.** | Het duurde te lang | Klik op **Opnieuw proberen**. |
| **De server is tijdelijk niet bereikbaar.** | De server of database heeft even een storing (fout 503) | Wacht even en probeer opnieuw. Je sessie blijft bewaard. |
| **Gepland onderhoud** | Er wordt een nieuwe versie geïnstalleerd | Wacht enkele minuten. |
| **Er ging iets mis.** | Dit scherm liep vast | Probeer opnieuw of ga terug. Je gegevens zijn niet verloren. |

## WAT GEBEURT ER DAARNA?

Zodra de verbinding terug is, werkt alles verder. De wachtrij verstuurt zichzelf.

## WAAR MOET JE OP LETTEN?

- Alleen scans, stopacties en incidentmeldingen gaan in de wachtrij. Kantoorwerk zoals een opdracht opslaan niet.
- Meld je niet af terwijl er acties wachten: afmelden wist de wachtrij.

## VEEL VOORKOMENDE PROBLEMEN

**De melding blijft.** Meld het aan je beheerder, met het tijdstip en wat je deed.
