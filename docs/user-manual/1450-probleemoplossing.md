## Eerst dit

1. Lees de melding op het scherm. Ze zegt meestal wat er aan de hand is.
2. Laad de pagina opnieuw.
3. Kijk of iemand anders hetzelfde aan het doen is.

## Wat lukt er niet?

| Probleem | Lees dit |
|---|---|
| Ik kan niet aanmelden | [Inloggen](help:inloggen) |
| Ik zie een scherm of knop niet | [Rollen en rechten](help:rollen-uitleg) |
| "Geen toegang" of "Niet gevonden" | [Geen toegang](help:geen-toegang) |
| "Intussen gewijzigd" | [Conflict](help:conflict) |
| De server of het netwerk werkt niet | [Serverproblemen](help:serverproblemen) |
| Een rit plannen lukt niet | [Waarschuwingen en blokkeringen](help:conflicten) |
| Een dossier afsluiten lukt niet | [Dossier afsluiten](help:dossier-afsluiten) |
| Een factuur definitief maken lukt niet | [Definitief maken](help:factuur-definitief) |
| Iets kan niet gefactureerd worden | [Facturatiecontrole](help:facturatiecontrole) |
| Een voertuig is geblokkeerd | [Inzetbaarheid](help:inzetbaarheid) |

## Hulp vragen

Geef aan je beheerder door:

- wat je deed en wat je verwachtte;
- de exacte melding;
- het tijdstip;
- het nummer van het dossier, de opdracht of de factuur.

Stuur nooit je wachtwoord door.
